 # Online Time Registration Service
 
 Online tool for our internal time registration and time account management
 
 ## Features
 
 - *Automatic time registration*: detects computer start and shutdown
 - *Manual adjustments*: employees can correct times and enter absences
 - *Interface to time accounting system*: data will be provided to the HR sytem
 
 ## Information Ressources
 
 - *Project folder*: "TimeRegService" in the common "Projects" path
 - *Team information*: subfolder "Teaminfo" in the project folder*
 - *Processes*: applicable processes in subfolder "Processes"
 - *Conventions*: naming conventions, workflows, et cetera in subfolder "Conventions"
